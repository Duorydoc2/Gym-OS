# RYDOC GymOS

> **The Operating System for Modern Gyms & Fitness Centers**

RYDOC GymOS is a client-first, privacy-focused gym management application built with zero external framework overhead. It enforces strict real-data integrity (no fabricated records or manufactured percentages) and offers instant local persistence with full export/import capabilities.

---

## ✨ Key Features

- **🛡️ Strict Real-Data Only**: Starts with clean zero-state metrics; all statistics, charts, and lists derive exclusively from records you enter.
- **🚀 4-Step Onboarding Wizard**: Quick setup for gym info, operating hours, billing preferences, and custom membership plans.
- **👥 Complete Member Lifecycle**: Member registration, plan assignment, validity tracking, fee balances, and profile drawers.
- **💳 Payments & Invoicing**: Record payments across Cash, UPI, Card, and Net Banking; counter UPI QR preview; printable receipts.
- **📅 Daily Attendance Register**: Fast check-in and checkout logging with real-time in-gym headcounts.
- **🏋️ Trainers Management**: Manage trainer profiles, specializations, shift timings, and member assignments.
- **📋 Membership Plans & Pricing**: Configurable pricing tiers, durations, and perks with live active subscriber counts.
- **🎯 Leads & Enquiries Pipeline**: Track prospective members with one-click conversion into active memberships.
- **📦 Stock & Inventory**: Monitor supplements and equipment with low-stock threshold alerts.
- **💬 WhatsApp Reminders**: Direct message previews with one-click clipboard copy and WhatsApp Web launcher.
- **⚡ Isolated Demo Sandbox**: Explore sample presentation data without touching or overwriting real records.
- **🎨 Dark & Light Modes**: Seamless switching featuring the signature RYDOC Neon Pink theme.
- **💾 Local Persistence & Data Freedom**: 100% browser-based LocalStorage with JSON export/import and permanent wipe options.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)

### Running Locally

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git

# Navigate into project directory
cd "Gym OS"

# Start the local server
npm start
```

Open your browser and navigate to:
```
http://localhost:3000
```

## 🛠️ Tech Stack

- **Structure**: Vanilla HTML5
- **Styling**: Vanilla CSS3 (Custom Design System, CSS Variables, Glassmorphism)
- **Logic**: Vanilla Modern JavaScript (ES6+, Reactive Store Pattern)
- **Persistence**: Browser LocalStorage
- **Server**: Lightweight zero-dependency Node HTTP server (`server.js`)
